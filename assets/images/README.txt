# TechAdvantX Copilot Fusion post assets

1. Upload the Markdown file to your Jekyll repository's `_posts/` folder.
2. Upload the `copilot-fusion` image folder to `assets/images/`.
3. Keep the folder name `copilot-fusion` unchanged; the Markdown references images under `/assets/images/copilot-fusion/`.
4. Review the front matter (especially date, categories, tags and author) against your repository's `_config.yml` conventions before committing.
5. Preview the site build before merging/publishing.

The Markdown preserves the article's wording, benchmark tables, section structure and embedded screenshots. It does not independently validate the benchmark claims.
